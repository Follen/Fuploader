# Fupload Skill 网页对齐工作流

用户显式选择第三方 Python NewBeeBox 管理工具时，Skill 将 Creator Center 网页行为视为发布契约。它先读取每个动作的 CLI help 与网页动态候选，再按网页父子依赖收集全部业务选择，生成一次最终 JSON，展示全部改变/保留/清空字段、附件、build、备份、商业/审核和频道影响，并取得一次写入确认。

Skill 不因网页功能与 `ncc` 文档不同而静默切换通道。默认官方 `ncc` 选择顺序保持不变；只有用户显式选择第三方 Python 通道时才执行网页对齐的 JSON 流程。它将每次计划保存到项目 `publish/`，写后读回，遇到不确定结果先只读核对，不记录凭据、签名 URL、原始 WA 或原始备份。
