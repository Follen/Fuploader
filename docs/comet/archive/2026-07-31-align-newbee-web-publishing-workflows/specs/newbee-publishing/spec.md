# NewBeeBox 网页发布协议

## 网页为业务基准

第三方 Python provider 的网页发布域包括插件、配置分享和 WA。Creator Center 网页的实际网络请求、表单初始值、控件依赖、禁用状态、提交 payload、错误反馈和 detail/list/version 读回是唯一业务契约。已安装 `ncc` 的文档与输出仅可作交叉核对，不能缩减、重命名或重新解释网页字段。

每种资源和动作都必须有可追踪的网页矩阵：页面入口、初始化 GET、动态 GET、请求 URL/方法、wire 字段与类型、默认值、条件必填、create/update/edit/delete 阶段、父字段、清空规则、上传动作、网页读回字段和错误语义。

## 表单状态机与 JSON

Python 在生成写 JSON 前先完成网页所需的 GET 依赖链，并只展示当前父项下的候选。父项包括游戏/build、分类、可见性/审核、订阅/付费/价格/有效期、频道开关、云备份、角色以及附件类型。改变父项时，所有网页会重置的子项必须从最终 JSON 中清除并重新查询；Python 在写入前用当前网页响应重复验证。

输入 JSON 仅包含用户选择、稳定 ID/selector 和本地文件引用。它不得包含网页 detail 原对象、统计/审核字段、签名 URL、cookie、token、原始 WA 字符串或原始云备份。对已有对象，Python 从当前网页 detail 恢复网页要求的完整 payload，并仅覆盖本动作允许的字段。

## 插件

插件 create/edit 覆盖网页公开的名称、简介、正文、来源、格式、分类、logo、截图、可见性、审核意图、订阅/商业字段和频道关联。Python 必须按网页 create 的默认和后续 edit 的锁定状态工作：create 不能错误地直接发布或携带网页不接受的后置字段；edit 不得发送网页禁用的字段，也不得漏掉网页仍可编辑的字段。

插件 update 覆盖网页版本、精确 build 字符串、压缩包、更新日志和网页允许的版本页字段。build 只能来自网页当前支持的精确版本集合，不得使用父分支 ID 或整组游戏版本代替。上传、版本 mutation 和版本/详情读回分别报告结果。

## 配置分享

配置 create/update/edit 覆盖网页元数据、媒体、可见性/审核、订阅/商业字段、频道、云备份和网页支持的插件/未知插件/素材/字体/角色选择。backup、角色和所有依赖内容均从网页当前动态响应选择；切换 backup 或角色会按网页清空下游选择。更新和编辑的省略/显式清空语义、保留的既有选择和 readback 必须与网页一致。

## WA

WA create/update/edit 覆盖网页游戏版本、名称、简介、说明、缩略图、图片、分类、来源、格式、订阅/商业字段、频道、附件、版本、更新日志和字符串内容。原始字符串不得出现在 CLI 输出或发布记录；读回使用网页可见的版本和脱敏长度/摘要。附件类型、上传协议、网页默认值和删除/替换语义都必须逐项对齐。

## 删除、错误和读回

删除前必须 GET 网页 detail 并验证当前作者拥有目标；delete JSON 只包含目标 ID 与显式确认。删除后用网页 list/detail 证明对象已不存在。删除结果不确定时不自动重试。

明确网页 HTTP/业务拒绝包含脱敏 endpoint、HTTP status、业务码和受限消息，并设置 `verification_required=false`。连接中断、timeout 或网页已接受 mutation 后读回暂不可见时设置 `verification_required=true`，调用方先读回，禁止自动重放。网页“提交审核”“审核中”“已发布”是不同状态，不能互相替代。

## 验证

合同测试覆盖所有网页可写字段、动态依赖、类型转换、默认/清空/保留、上传、明确拒绝和不确定写入。真实验证只使用明确命名的私有临时插件、配置和 WA，执行 create/update/edit/delete 并在每步以网页读模型确认。探索赛季不做真实写入。
