# Outcome

交付一个以 Agent Skill 为核心的新手盒子发布工具：`Fupload` Skill 负责询问用户要执行的发布动作、收集并整理资料、展示待执行内容，然后调用 Go/Cobra CLI 完成原子化业务操作。CLI 当前完整支持新手盒子，同时保留可扩展的平台边界，以后可以加入网易 DD，而不破坏现有命令和 Skill 工作流。

# Scope

- 使用 Go 和 Cobra 构建 `fupload` CLI。
- 新手盒子插件能力：列出/读取插件、创建插件元数据、编辑插件元数据、发布新版本；英文资源命令统一使用 `plugin`。
- 新手盒子配置分享能力：列出客户端已上传的云端备份、列出/读取配置发布、基于所选云端备份创建配置分享、更新配置分享。
- 新手盒子资料发现能力：读取单个云端备份的安全详情，并列出服务端当前分类与游戏版本，Agent 不猜测 ID、不要求用户手抄可查询字段。
- 每个根命令、中间命令和叶子命令都有完整 `help`，说明用途、必填输入、示例、写入效果和失败条件。
- CLI 自动复用本机已登录的新手盒子状态；不把登录流程作为本次面向用户的命令能力。
- 创建 `Fupload` Skill。Skill 先识别用户要上传新插件、编辑插件说明、发布插件新版本、创建配置分享或更新配置分享，再收集资料并调用一个原子 CLI 命令。
- 配置分享只使用用户已经通过新手盒子客户端上传的云端备份；Skill 必须查询并让用户选择备份，不实现本地 WoW 配置打包和云备份上传。
- 平台层当前只注册 `newbee` 实现，并定义后续网易 DD adapter 的边界。

# Non-goals

- 不支持网易 DD 的真实接口调用。
- 不实现手机验证码、网页验证码或交互式登录。
- 不实现客户端的 WoW 本地目录扫描、WTF/插件/字体压缩和云备份上传。
- 不支持 WA/字符串、攻略、删除内容或批量发布。
- 不绕过新手盒子审核，也不把“已提交公开”误报为“审核已通过”。

# Acceptance examples

- 用户要求“上传一个新插件”时，`Fupload` 询问插件名称、分类、简介、详情、图片、首个版本和公开策略等缺失资料，展示完整计划并取得一次确认，然后依次调用插件创建和版本发布命令；需要公开时最后调用编辑命令提交审核。
- 用户要求“更新插件 123 到 1.2.3”时，`Fupload` 收集压缩包、游戏版本和 changelog，核对目标插件后只调用发布新版本命令。
- 用户要求“修改插件说明”时，`Fupload` 读取当前插件详情、只收集需要变化的字段，并调用插件编辑命令，不上传新版本。
- 用户要求“发布配置”时，`Fupload` 明确告知配置必须已在客户端上传，查询可用云端备份并让用户选择，然后收集标题、正文、封面和关联/忽略项，调用配置创建命令。
- 用户要求“更新配置”时，`Fupload` 先确认目标配置发布 ID；若更换云端备份，再次让用户从已上传备份中选择，然后调用配置更新命令。
- `backup get` 返回可直接用于配置输入的已知插件关联、未知插件/材质/字体候选和角色候选，但不返回备份下载地址、ZIP 地址、哈希或原始配置内容。
- 分类和游戏版本由 CLI 从新手盒子公开元数据读取，Agent 能按名称向用户展示并选择真实 ID。
- 线上审计完整跑通插件创建、版本发布、元数据编辑，以及配置创建、元数据更新、切换云备份更新；每一步写后都使用只读命令核对远端结果。
- 插件版本发布和元数据编辑使用现有 `AyijeCDM 酒仙专用`（ID 20745）验证；元数据编辑在验证后恢复原字段，插件创建使用独立审计插件。
- `fupload <任意命令路径> --help` 能给出该层级准确、详尽的中文帮助和至少一个可执行示例。
- 选择尚未实现的平台时，CLI 返回稳定的“平台未支持”错误，不会错误调用新手盒子。
- 新手盒子命令使用 `fupload newbee ...`；未来网易 DD 使用稳定平台 ID `dd`，命令形态为 `fupload dd ...`。

# Constraints and invariants

- Skill 显示名严格为 `Fupload`。
- 每个写命令只表达一个服务端业务动作；创建、编辑和发布新版本不得合并为隐式复合写入。
- Skill 可以在一次总确认后按计划编排多个原子写命令；任一步失败必须停止，不执行后续步骤，并报告已成功步骤及其远端 ID。
- 更新已有插件说明、发布插件新版本和更新配置分享的最终目标状态固定为公开；若平台需要审核，则结果是已提交/重新进入审核，不承诺立即审核通过。
- 新手盒子配置创建/更新引用已有 `cloud_id`，不接受本地配置 ZIP 作为替代。
- CLI 的业务层不能直接依赖 Cobra，平台实现通过稳定接口与命令层隔离。
- 新手盒子与未来网易 DD 不能通过散落的条件判断耦合；平台注册与 adapter 必须可扩展。
- token、预签名 URL 和用户隐私不得出现在 help、错误详情或普通日志中。
- 所有 API 成功同时要求 HTTP 成功和业务 `code == 1`。
- 插件压缩包沿用服务端限制：`.zip`、`.rar`、`.7z`，最大 300 MB，上传超时至少 10 分钟。

# Decisions

- 2026-07-30：产品以 `Fupload` Skill 为核心，CLI 是 Skill 调用的原子执行层。
- 2026-07-30：首版只支持新手盒子；代码结构为网易 DD 预留平台 adapter，不提供伪实现。
- 2026-07-30：配置分享依赖用户已在客户端上传的云端备份，Agent 负责查询、询问和选择，不负责上传备份。
- 2026-07-30：插件写语义拆为创建元数据、编辑元数据、发布新版本三个独立动作。
- 2026-07-30：平台作为一级命令路径；当前使用 `newbee`，未来网易 DD 的平台 ID 固定为 `dd`。
- 2026-07-30：写命令统一使用 `--input <file>` 读取 YAML/JSON，或使用 `--input -` 从标准输入读取 JSON；复杂业务字段不提供重复的 flags 接口。
- 2026-07-30：写命令收到合法输入后立即执行；CLI 提供可选 `--dry-run`，不要求额外 `--apply`。Skill 在调用前承担用户确认。
- 2026-07-30：Skill 对完整用户目标只确认一次，然后连续编排必要的原子 CLI 命令；失败即停并保留进度说明。
- 2026-07-30：插件资源命令使用 `plugin`；结构化输出使用 `--output json`，Skill 始终启用该模式。
- 2026-07-30：新建内容未明确要求公开时保持私有；更新已有插件说明、发布插件新版本和更新配置分享时直接设置公开并接受平台审核。
- 2026-07-30：用户确认当前 brief 与完整目标规格，可以进入实现。
- 2026-07-30：用户授权进行真实线上写入审计；专用审计插件和配置可能保留并进入审核。
- 2026-07-30：用户改为授权在 `AyijeCDM 酒仙专用`（ID 20745）测试发布新版本和编辑信息；编辑后恢复原字段，审计版本记录可能永久保留。

# Verification expectations

- Go 单元测试覆盖命令参数校验、平台路由、请求序列化、响应错误处理和敏感字段脱敏。
- 使用本地 HTTP test server 验证新手盒子插件/配置各原子命令的 endpoint、请求方法、header、JSON 或 multipart 字段，不在自动测试中写入真实线上内容。
- 使用当前已登录账号受控执行六个线上写场景，保存脱敏后的命令、字段摘要、远端 ID、响应结构和写后读取结果；遇到首个失败即停止后续写入。
- 自动遍历 Cobra 命令树，验证每个命令都有非空 Long help、示例和参数说明。
- Skill 静态检查验证名称为 `Fupload`、工作流覆盖五类目标动作，并明确要求配置云端备份已由客户端上传。
- 构建 Windows 可执行文件并执行根命令、平台命令和所有叶子命令的 `--help` smoke test。
