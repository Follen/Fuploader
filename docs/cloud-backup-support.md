# 四个平台的配置分享与云备份范围

按 2026-10-30 用户要求，新手盒子（NewBeeBox）、黑盒工坊、ModUs、网易 DD 都纳入支持范围。不能只实现黑盒。

## 共同目标

- 查询云备份及其可选插件、材质、字体、WTF 子账号、服务器和角色。
- 从本地明确选定的内容生成并上传云备份，读回确认；不把仅查询现有备份称为支持生成。
- 创建及更新配置分享；优先保留已有记录，仅更改明确选定的内容、文字和版本，完整保留其他富文本和设置。
- 备份单条删除及批量删除预览，逐项记录结果。已被配置分享关联的备份必须拒绝删除，不能通过确认参数绕过。
- 删除前重新检查关联；查询失败、分页未读完或关联状态未知时不执行删除。平台原子拒绝已关联删除的能力也须分别确认，不能把客户端预检当成服务端事务保证。
- 分别验证正式服及各怀旧服的内容与角色选择、审核状态、失败后的读回及清理。

## 开发分支实现

| 平台 | 基于已有备份的配置分享 | 备份查询 | 备份生成 | 备份删除 |
| --- | --- | --- | --- | --- |
| NewBeeBox | Python 创建、更新、编辑；官方 ncc 有能力差异 | 列表、详情、改名 | 明确选择后生成、上传 | 预览、单条、批量、引用保护 |
| 黑盒工坊 | 创建、更新、编辑、删除，保留完整富文本 | 列表、详情、改名 | 明确选择后生成、上传 | 预览、单条、批量、引用保护 |
| ModUs | 创建、更新、编辑 | 列表、详情、改名 | 明确选择后生成、上传 | 预览、单条、批量、引用保护 |
| 网易 DD | 创建、更新、编辑 | 列表、详情、改名 | 明确选择后生成、上传 | 预览、单条、批量、引用保护 |

代码使用各自官方客户端的协议，统一命令入口为 `<platform> backup scan|generate|upload|create|list|get|rename|delete-preview|delete`，各平台字段与文件格式见 Skill 的平台参考。单条删除也使用只含一个 ID 的 `backup_ids` 数组。删除只接受明确的 ID 和 `confirm_delete:true`；筛选条件用于预览，不直接用于删除。

配置正文、更新记录和图片引用完整输出；凭据及导入字符串仍脱敏。预览检查全部自有配置分享，执行前再次检查，引用不明或分页异常时停止。此保护在 Fupload 客户端执行，尚未确认平台服务端具备原子引用保护。

2026-10-30 真实验收：新手盒子 7 个动态分支、DD 6 个动态分支、ModUs 5 个 Build 均完成合成备份的生成、上传、改名、删除及读回；黑盒 6 个动态分支也全部完成相同备份流程，正式服和周年服另完成私密配置创建、更新、编辑、删除及富文本/图片/角色保留验证。四个平台均以本次新建的私密配置验证关联备份硬拒删，随后按配置、备份顺序清理。原有备份与分享保留。黑盒短信/微信及每次使用时续期已验证；DD 全程借用现有会话，不关闭或重新登录客户端。全部字段、证据和具体限制见[平台字段总表](../fupload/references/platform-fields.md)。
